Question 1 — Two-Link Robot Arm Workspace Visualisation

A two-link planar robot arm consists of Link 1 of length L1 inclined at angle θ1 to the horizontal, and Link 2 of length L2 inclined at angle θ2 relative to the axis of Link 1. Both links are attached at the origin (base).

  1. Write the forward kinematics equations for the position of the elbow joint and the end-effector as functions of L1, L2, θ1, and θ2.
  2. Write a Python script that, for user-defined values of L1 and L2, sweeps both joint angles over their full range θ1 ∈ [0°, 90°] and θ2 ∈ [0°, 180°] using a suitable angular step size of your choice (justify your choice in a comment).
  3. Plot the complete reachable workspace — all points swept by the entire arm (both links), not just the end-effector. Each link should be visually distinguishable in the plot.
  4. Demonstrate your script for the case L1 = 1.0 m and L2 = 0.6 m. Include appropriate axes labels, title, and a legend.

[ 30 Marks ]

Question 2 — Discrete-Time System Identification using iGD

A physical system was excited with a unit step input and its output was recorded over time. The measured data (input and output time series) are provided in the accompanying file RDA211_Q2_SystemData.xlsx (Sheet: System Data; columns: Time, Input u(t), Output y(t)). The output contains realistic measurement noise.

  1. Load the data from the Excel file using Python. Plot the input and output signals on the same time axis to visually inspect the system behaviour.
  2. Using the iGD (iterative Gradient Descent) method as taught in this course, identify the discrete-time model of the system. The system is known to be second order; however, you must determine the model coefficients from the data. State your chosen step size and justify it.
  3. Convert the identified discrete-time model to a continuous-time transfer function in the Laplace domain using the appropriate transformation, and state the final transfer function G(s) clearly.
  4. Simulate the identified model's response to the same step input and overlay it against the original measured output. Comment on the quality of fit.
  5. State the natural frequency ωn and damping ratio ζ implied by your identified G(s), and interpret what these values tell you about the physical system.

[ 30 Marks ]
