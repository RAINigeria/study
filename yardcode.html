# YARD Code — Talking Points for the National Addressing Council ## 1. Opening: What Is YARD Code? - YARD Code is a **digital addressing system** that assigns every square meter of land a unique alphanumeric code. - The code is derived **mathematically from GPS coordinates** — no manual mapping required. - The alphanumeric format is modeled after systems like the UK's postcode logic, but simplified: a short code such as **GQ9U88** identifies a location, and an optional consonant-vowel-consonant-vowel suffix (e.g., **GQ9U88-TCUV**) narrows it down to a precise spot within that unit. - Critically, **internet access is not required** — YARD Code works fully offline, computed like a calculator, which means it works everywhere in the country, including remote and underserved areas. - A mobile app already exists and is functional. ## 2. How It Works - Every user can look up their own YARD Code and share it so others can find them. - The platform **links YARD Code to Google Maps**, so once you know a destination's code, you can pull an actual route to get there. - **Route Code**: a string of YARD Codes recorded as someone moves from Point A to Point B — effectively crowd-sourced route data, obtainable by anyone recording their journey. - **Boundary Code**: generated by walking, flying, or drawing around a piece of land — gives that parcel a unique, verifiable boundary identity. - The system converts back and forth between YARD Code, GPS coordinates, and street names. - Street names currently come from Google Maps, but YARD Code includes a **crowdsourcing feature** letting citizens submit their own street names — creating a path to a fully Nigerian-owned street/address database, the same way Google originally built its own. ## 3. Existing Institutional Support - Discussions are already underway with the **Surveyor General's office** and the **Space Research and Development Agency (NASRDA)**, both of whom have expressed willingness to support deployment. - This positions YARD Code as a technology that already has technical validation and institutional interest — what's missing is policy backing and funding. ## 4. Benefits to Government - **Infrastructure planning & conflict detection**: Route Code and Boundary Code can instantly flag whether a planned road, railway, waterway, pipeline, or fiber-optic route will cross or infringe on an existing property boundary. - **Land dispute prevention**: If a boundary code has already been assigned to someone else, a buyer can immediately see that the land is already claimed — reducing fraudulent double-sales. - **Address verification**: Needed by banks, courts (for bail), and government agencies (NIN registration, phone line registration, etc.). Nigeria currently relies on foreign address-verification solutions; YARD Code offers a sovereign, local alternative. - **Data sovereignty & security**: Because address verification data is sensitive, YARD Code is being built with encryption designed to prevent foreign cloud services from accessing Nigerian address data. - **Safety and speed monitoring**: The platform can support real-time safety monitoring — for example, a "check-in" feature where failure to respond to a prompt (e.g., missed PIN entry) automatically alerts rescuers and routes the nearest available support to the person's location. This could be made compulsory for anyone traveling on official government duty. - **Logistics and asset tracking**: Government-delivered assets — even at sea or in remote zones — can be tracked without requiring internet access. - **Military/defense use case**: In forest or remote combat zones, personnel can pull recorded YARD Code routes of colleagues to trace and locate them, even where GPS-based apps would otherwise fail without connectivity. ## 5. Benefits to Business Stakeholders — How They Can Make Money - **Own the underlying data asset**: Nigeria currently pays foreign companies (like Google) for addressing/street APIs, because they hold the data. YARD Code offers a path for **local, patriotic ownership** of the national street/GPS coordinate database — with global players like Google eventually paying *Nigerian* entities for access, instead of the reverse. - **Address verification as a service**: Address verification isn't free and doesn't need to be a one-time event — it can be structured as an expiring, renewable service. A policy could make **local platforms** (not foreign ones) the compulsory backbone for this, given how sensitive constant-location verification is. - **Boundary Code services**: A dedicated commission, agency, or private organization could be established purely to administer and monetize Boundary Code issuance and verification. - **Delivery & logistics**: Point-to-point and last-mile delivery companies can integrate YARD Code for precise, offline-capable location data — a major efficiency gain over street-address-based delivery. - **Advertising revenue**: The platform itself can host adverts, since it becomes a daily-use utility for routing, storing, and revisiting saved locations ("Stored Yards"). - **Verified digital property listings**: Enables "neat, verified addresses" for real estate — supporting a form of digital land governance and reducing fraud in property sales. - **Safety-monitoring subscriptions**: The personal safety/check-in feature is a natural product for individuals, corporates (staff safety), and eventually government-mandated travel compliance. ## 6. The Ask — How Stakeholders Can Support - **Build the database together**: Invite stakeholders to co-build Nigeria's street-level GPS/addressing database through YARD Code's crowdsourcing tools. - **Funding**: The technology already exists — what's needed now is capital to scale collection and deployment. - **Policy**: Government should consider policy that keeps address verification and street-data ownership **localized** — i.e., mandating that this class of data and service be handled by local/Nigerian platforms rather than foreign ones. - **Framing for the room**: "The technology is already here. What we need from this Council is the policy that drives adoption, and the funding that scales it." ## Closing Line (suggested) > "Google built a global addressing empire from data it collected freely from us. YARD Code gives Nigeria the chance to own that data ourselves — and to turn it into safety, into infrastructure planning, into commerce, and into revenue that stays local."
