Denavit-Hartenberg (DH) Parameterisation

DH parameters describe each joint with 4 numbers: link length a, link twist α, joint offset d, and joint angle θ. The transformation matrix T for each joint is computed from these.

Jacobian Matrix Derivation

The Jacobian J(q) maps joint velocities q̇ to end-effector velocity ẋ: ẋ = J(q) · q̇. Each column j gives ∂p_EE/∂qⱼ.
