Option A — 2D Environment Scanner with Motion Detection
Option A
2D LiDAR Scanner + Human Presence Detector
30 marks

Build a rotating distance scanner that maps a 2D slice of its environment using a Time-of-Flight (ToF) sensor mounted on a DC motor with encoder feedback. The system must continuously scan, track angle at each measurement, and detect when a change appears in the environment that was not there in the last 5 minutes — indicating human presence — then alert.

VL53L0X / VL53L1X ToF Sensor DC Motor + Motor Driver (L298N) Hall Encoder or Rotary Encoder Arduino / ESP32 LED + Serial Monitor Alert
[ ToF Sensor ] ──→ reads distance at each encoder angle [ Encoder ] ──→ reports current rotation angle (0–360°) [ DC Motor ] ──→ rotates the ToF sensor continuously [ MCU Logic ] → store baseline scan map (angle + distance) every 5 minutes → on each new scan, compare reading vs baseline at same angle → if Δdistance > threshold at any angle → ALERT (LED on + Serial Monitor prints angle + delta)
  1. Motor + encoder: Rotate the motor at a consistent speed. Use the encoder to track the current angle in degrees.
  2. ToF scan: At each encoder step, read distance from the ToF sensor. Store as (angle, distance) pairs for a full rotation.
  3. Baseline map: Store the first complete scan as the reference environment. Refresh this baseline every 5 minutes automatically.
  4. Change detection: On each new scan, compare every angle's distance to the baseline. If any reading differs significantly (e.g. ≥15 cm), flag it.
  5. Alert: Activate an LED and print to Serial Monitor — show which angle changed and by how much.
  6. Continuous: System must run indefinitely without needing a manual reset.
Option B — MQTT Height Reporter with Live Web Display
Option B
Doorway Height Sensor → MQTT → Browser Dashboard
30 marks

Build a system that measures the height of a person passing under a doorway using a downward-facing sensor, publishes each reading to an MQTT broker, and displays the latest received height on a webpage running on your laptop. The sensor must only trigger when a person is actively present — not continuously polling.

VL53L0X or HC-SR04 Ultrasonic ESP8266 / ESP32 MQTT Broker (HiveMQ / Mosquitto) HTML + MQTT.js Web Page
[ Sensor facing downward from doorframe ] → detects presence (reading drops below threshold) → computes: height = door_height − sensor_distance → publishes to MQTT topic: rain/doorway/height [ MQTT Broker ] (WiFi) [ Laptop Browser ] → subscribes to topic via MQTT.js (WebSocket) → displays last received height on screen → does NOT update unless a new person arrives
  1. Presence gate: Only publish when something is detected under the doorway (reading below a set threshold). Do not publish when the doorway is empty.
  2. Height calculation: Height = known door height − sensor distance reading. Calibrate this before the exam demo.
  3. MQTT publish: Connect ESP to WiFi, connect to broker, publish computed height to your defined topic each time a person passes.
  4. Web page: An HTML file opened in your laptop browser subscribes to the MQTT topic using MQTT.js over WebSocket. Display the last height prominently. It must not update unless a new message is received.
  5. Demo: Walk a person under the sensor — height appears on screen. Show the supervisor that nothing updates when the doorway is clear.
Option C — LDR Hallway Entry / Exit Detector
Option C
LDR Array — Direction-Aware Occupancy Counter
30 marks

Using a row of LDRs (Light-Dependent Resistors) placed across a hallway entrance, build a system that detects whether a person is entering or leaving based on the sequence in which the LDRs are triggered. Log each ENTRY or EXIT event to the Serial Monitor and maintain a running count of people currently inside.

LDRs (minimum 2, ideally 3–4) Resistors (voltage divider) Arduino / ESP32 Optional: I2C LCD Display
Top view of hallway entrance: OUTSIDE [ LDR-1 ] [ LDR-2 ] INSIDE ──────────────○──────────○────────────── LDR-1 blocked first → then LDR-2 = ENTRY LDR-2 blocked first → then LDR-1 = EXIT Serial Monitor output: → "ENTRY detected — People inside: 3" → "EXIT detected — People inside: 2"
  1. Wiring: Mount at least 2 LDRs across the entrance (one outer, one inner). Wire each as a voltage divider to an analog input pin.
  2. Calibration: Read ambient light values and set shadow-detection thresholds appropriate for your lab lighting conditions.
  3. Sequence detection: Track which LDR is shadowed first within a configurable time window (e.g. 2 seconds). Outer first = ENTRY. Inner first = EXIT.
  4. Logging: Print ENTRY or EXIT to Serial Monitor with the updated count of people currently inside.
  5. Edge case: If only one LDR is triggered and the sequence is never completed (person stops mid-way), ignore the event.
  6. Bonus: Display current count on an I2C LCD or a row of LEDs.
